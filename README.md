Инкапсуляция: Поля класса сделаны приватными (через двойное подчеркивание __ или одинарное _ в Python принято использовать одинарное для "protected", но для учебного задания часто просят двойное). Доступ к ним осуществляется через геттеры и сеттеры (@property).
Конструктор: __init__ позволяет создавать объект как с параметрами, так и без (по умолчанию).
Деструктор: __del__ реализован формально, так как в Python управление памятью автоматическое.
Хранение данных: Используется стандартный список list, который является динамическим массивом.
Логика стажа: Стаж вычисляется как разница между текущим годом (datetime.datetime.now().year) и годом поступления.
